📲 Otis als app installeren

Upload 3 bestanden naar GitHub. Dan zie je "App installeren" in Chrome — geen snelkoppeling maar een echte app!

Stap 1
GitHub account + repository
github.com → gratis account → + → New repository → naam: otis → README aanvinken → Create.
Stap 2
Upload alle 3 bestanden
Add file → Upload → sleep erin:
index.html   manifest.json   sw.js
→ Commit changes
Stap 3
GitHub Pages aanzetten
Settings → Pages → Source: main → Save. Wacht ~1 min.
Stap 4
Open in Chrome op telefoon
https://[gebruikersnaam].github.io/otis
Stap 5 — Installeren als app!
Chrome menu ⋮ → "App installeren"
Je ziet nu "App installeren" ipv "snelkoppeling". Dit werkt door manifest.json + sw.js. Microfoon en meldingen werken nu ook! 🎉
