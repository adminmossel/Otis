📲 Otis als app installeren

Zo zet je Otis op je startscherm via GitHub Pages (gratis, geen account vereist voor bezoeken):

Stap 1
Maak een GitHub account
Ga naar github.com en maak een gratis account aan als je er nog geen hebt.
Stap 2
Maak een nieuw repository
Klik op het + icoontje → "New repository". Geef het de naam:
otis
Vink "Add a README file" aan, dan "Create repository".
Stap 3
Upload otis.html als index.html
Klik op "Add file" → "Upload files". Sleep het gedownloade otis.html bestand erin en hernoem het naar:
index.html
Klik "Commit changes".
Stap 4
Zet GitHub Pages aan
Ga naar je repository → Settings → Pages. Onder "Source" kies je main branch. Klik Save.
Stap 5
Open de link in Chrome op je telefoon
Je URL wordt:
https://[jouwgebruikersnaam].github.io/otis
Open deze link in Chrome op je Android.
Stap 6 — Installeren!
Toevoegen aan startscherm
In Chrome: tik op de ⋮ drie puntjes rechtsbovenin → "Toevoegen aan startscherm". Otis verschijnt als echte app op je startscherm! Microfoon, meldingen — alles werkt nu. 🎉
